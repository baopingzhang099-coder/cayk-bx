# 保险模块功能清单

## 一、保险购买模块

### 1.1 投保信息管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **投保信息录入** | 客户基本信息 | 支持企业用户填报、系统导入客户基本信息，包含企业名称、联系人、联系方式、企业资质等字段 |
| | 买方信息 | 支持客户填报/贸易资料解析采集买方信息，包括买方名称、信用评级、历史交易记录等 |
| | 贸易信息 | 通过贸易资料解析获取贸易相关信息，包括商品信息、交易金额、付款方式等 |
| | 购买需求 | 支持客户填报/录入保险购买需求，包括投保金额、保障范围、预期保险公司偏好等 |
| **投保信息数字化** | 投保资料整理 | 对客户提交资料和贸易资料进行系统化整理，形成完整的投保档案 |
| | 保险购买需求整理 | 根据客户需求和贸易信息，整理形成标准化的保险购买需求文档 |
| | 投保申请资料整理 | 整理生成投保申请书、买方信息采集表等正式投保申请材料 |

### 1.2 投保流程管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **投保方案确认** | 投保方案推介 | 根据客户投保需求、贸易信息、国别行业风险等条件，系统自动匹配并推荐保险方案 |
| **申请投保** | 申请投保 | 平台自动提取投保申请书、买方信息采集表等资料，生成投保申请单 |
| **提交投保申请** | 提交投保申请 | 完成流程校验和任务管理，支持线上提交投保申请至保险公司 |
| **审核流转** | 审核流转 | 管理投保申请的审核流程，跟踪各审核节点状态，处理审核意见反馈 |
| **核保** | 核保 | 配合保险公司进行核保流程管理，接收核保结果并反馈客户 |
| **保单签发** | 保单获取 | 获取保险公司签发的正式保单，支持电子保单接收和解析 |
| **支付管理** | 支付管理 | 提取保单明细表、费率表信息，管理保费支付流程，跟踪支付状态 |

### 1.3 数据报表管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **保单数字化** | 信息字段整理 | 从流程中提取关键字段，整理保单编号、被保险人、保险公司、保险期限等核心信息 |
| | 流程整理 | 梳理投保全流程节点和时间线，形成标准化流程记录 |

## 二、保单管理模块

### 2.1 保单信息管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **保单数字化** | 信息字段整理 | 支持客户录入/系统提取保单及批单信息，整理保单号、保险公司、保险期限、保险金额等字段 |
| | 流程整理 | 梳理保单全生命周期流程，记录各节点状态变更和时间节点 |
| **管理需求整理** | 管理需求整理 | 支持客户录入管理需求，包括保单变更申请、批单申请等 |

### 2.2 贸易信息管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **贸易数字化** | 贸易信息录入 | 支持客户录入完整的贸易信息，包括合同号、商品信息、交易金额、付款条件等 |
| | 字段提取 | 按照贸易字段清单和数据要求，提取关键贸易数据字段 |
| | 贸易与保单匹配 | 根据保单与贸易匹配规则，建立贸易信息与保单的关联关系 |

### 2.3 信用限额管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **申请限额** | 申请资料整理 | 客户录入信用限额申请信息，整理生成信用限额审批表、买方信用限额申请表等材料 |
| | 限额审批规则 | 按照各保险公司限额审批要求（审批周期、审批条件等）进行规则校验 |
| **限额数据整理** | 限额数据提取 | 从保单提取已用额度，从跟单员跟进获取最新审批额度，整理形成限额台账 |
| | 字段提取规则 | 按照限额字段提取规则，自动提取买方名称、信用额度、已用额度、剩余额度等字段 |
| **限额调整** | 使用调整 | 当出运申报或理赔发生时，根据各保险公司信用限额规则（使用比例、剩余额度）自动更新限额状态 |
| | 被动调整 | 跟单员跟进各保险公司限额调整通知，系统被动接收并更新限额数据 |
| **关联提示** | 超限额拦截 | 当买方信用额度不足或即将超限时，系统自动拦截并提示相关业务人员 |
| | 信用限额变动提醒 | 当买方信用限额发生变动时，系统自动推送提醒通知给相关跟单员和企业用户 |

### 2.4 出运申报管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **出运申报资料整理** | 申报时效校验 | 按照各保险公司出运申报规则校验申报时效（应在规定时间内完成申报） |
| | 金额匹配校验 | 按照出运申报规则校验出运金额与保单限额、买方限额的匹配关系 |
| | 资料清单生成 | 根据贸易数据关联规则、保单匹配规则，生成出运申报资料清单 |
| **出运流程管理** | 出运信息录入 | 客户录入出运申报单信息，包括出运日期、商品信息、离岸金额、目的地等 |
| | 第三方数据对接 | 对接报关数据等第三方数据源，自动获取/核验出运申报信息 |
| | 申报提交 | 整理出运申报资料，提交至保险公司或相关审核机构 |
| | 申报审核 | 管理出运申报的审核流程，跟踪审核状态，处理审核意见 |

### 2.5 流程管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **生效通知** | 生效通知 | 当保单生效时，根据各保险公司保单期限规则自动更新保单状态并发送生效通知 |
| **中止通知** | 中止通知 | 当保单因故中止时，更新保单状态并发送中止通知（需审核申请文件） |
| **退保管理** | 退保管理 | 处理保单退保申请，跟踪退保流程，处理退保退款事宜 |
| **到期提醒** | 到期提醒 | 在保单到期前自动发送提醒通知，便于客户及时续保 |
| **续保通知** | 续保通知 | 对接到保险购买模块，当保单即将到期时自动触发续保流程通知 |

### 2.6 保费补贴管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **补贴申请** | 补贴申请发起 | 根据系统提醒或跟单员手动跟进，按照各区域保费补贴申请规则发起补贴申请 |
| | 申请状态跟踪 | 跟踪补贴申请在各政府部门的审批进度 |
| **资料整理** | 补贴资料整理 | 按照各区域政府部门要求，整理并提交保费补贴申请所需资料 |
| **流程跟进** | 流程状态更新 | 实时更新补贴申请流程状态，反馈给企业用户 |
| **补贴到账** | 到账提醒 | 当保费补贴款项到账时，系统自动发送到账提醒通知 |

### 2.7 数据报表管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **保单履约情况** | 履约数据统计 | 统计各保单的履约情况，包括正常履约、逾期、未决案件等 |
| | 履约报表生成 | 生成保单履约情况统计报表 |

## 三、保险理赔模块

### 3.1 理赔信息管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **理赔信息录入** | 客户基本信息 | 支持企业用户填报/系统导入理赔客户基本信息，包括企业名称、事故概况等 |
| | 买方信息 | 支持客户填报/贸易资料解析获取买方相关信息，用于关联出运合同 |
| | 贸易信息 | 通过贸易资料解析获取贸易相关信息，确认出运记录和交易背景 |
| | 保单信息录入 | 上传/解析保单信息，或直接对接保单管理模块获取保单数据 |
| | 保单履约信息录入 | 客户录入/系统对接保单履约相关信息，包括应收账款信息、付款记录等 |
| | 理赔管理需求 | 客户填报/录入理赔管理具体需求，如理赔报案类型、期望处理方式等 |
| **理赔信息数字化** | 理赔资料整理 | 对客户提交的理赔资料和贸易资料进行系统化整理归档 |
| | 理赔申请资料整理 | 按照各保险公司理赔所需资料清单，整理生成理赔申请书等正式材料 |
| | 理赔结果初判 | 根据各保险公司拒赔案例和理赔审核标准，对理赔申请进行初步判断 |

### 3.2 理赔流程管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **理赔报案** | 报案登记 | 客户录入/关联贸易流程发起理赔报案，提交可能损失通知书 |
| | 承保范围校验 | 按照各保险公司承保范围要求，校验出险事故是否在承保范围内 |
| | 派单规则 | 根据派单规则将理赔案件分配给相应的跟单员或理赔人员 |
| **理赔申请** | 风险提示 | 当发现潜在风险点时，系统自动进行风险提示 |
| | 申请资料提交 | 按照理赔资料清单要求，整理并提交理赔申请材料 |
| **资料移交** | 流程校验 | 对理赔资料的完整性和规范性进行校验 |
| | 任务管理 | 管理理赔案件在各环节的任务分配和流转 |
| | 资料移交 | 将审核通过的资料移交至保险公司，按照各公司理赔流程规则（期限、节点）处理 |
| **审核调查** | 审核调查 | 配合保险公司进行理赔案件的审核调查工作，跟踪调查进度 |
| **核损与定损** | 核损定损 | 配合保险公司进行损失的核定和金额的确定 |
| **理赔决定** | 理赔决定 | 获取保险公司最终的理赔决定结果 |
| | 关联产品处理 | 如涉及其他关联产品，按照关联产品规则进行处理 |
| **赔款支付** | 赔款数据提取 | 提取理赔决定书中的赔款金额信息 |
| | 支付流程 | 按照支付规则管理赔款支付流程，生成费用通知单 |
| **建议策略** | 策略建议 | 根据理赔案件分析结果，关联其他产品提供风险防范和业务拓展建议 |

### 3.3 数据报表管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **案件处理报告** | 报告生成 | 按照分析报告模板生成理赔案件处理报告 |
| **追偿进度报表** | 追偿进度统计 | 统计追偿案件的处理进度和追偿成果 |
| | 报表生成 | 按照统计报表模板生成追偿进度报表 |

## 四、跟单员管理模块

### 4.1 信息管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **信息录入** | 基本信息 | 管理员录入跟单员基本信息，包括姓名、联系方式、工号、部门等 |
| | 从业信息 | 录入跟单员从业信息，包括从业资质、专业领域、工作经历等 |
| | 账户信息 | 维护跟单员系统账户信息，包括登录账号、密码管理、身份认证等 |
| **信息维护** | 信息必填校验 | 按照信息必填校验规则，校验跟单员信息的完整性和规范性 |
| | 身份真实性验证 | 按照身份真实性要求，对跟单员身份信息进行核实验证 |

### 4.2 权限管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **权限配置与变更** | 权限配置 | 管理员为跟单员分配系统操作权限，包括模块访问权限、数据操作权限等 |
| | 权限变更 | 当跟单员岗位职责调整时，管理员可变更其系统权限 |
| | 权限回收 | 当跟单员离职或岗位变动时，管理员可回收其系统权限 |
| | 权限查询 | 支持查询跟单员当前拥有的权限明细 |

### 4.3 业务管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **任务分配与跟进** | 系统派单 | 按照派单规则自动将业务任务分配给跟单员 |
| | 自行抢单 | 支持跟单员自行抢接业务任务，提高业务处理效率 |
| | 代办任务分配 | 管理员可手动将代办任务分配给指定跟单员 |
| | 进度跟踪 | 跟踪跟单员业务处理进度，记录各节点处理时间和状态 |
| | 业绩统计 | 按照各环节常量期限要求和实际处理情况，统计跟单员业绩数据 |
| **处理记录** | 处理记录查询 | 支持查询跟单员历史业务处理记录 |
| | 统计报表 | 生成跟单员业务处理统计报表 |

### 4.4 考核管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **考核评级** | 服务评价 | 收集客户对跟单员服务的评价信息 |
| | 违规记录 | 记录跟单员在业务处理过程中的违规行为 |
| | 考核评级 | 根据跟单员的服务评价、违规记录等，按照评级周期和扣分规则进行考核评级 |
| **评价与结果** | 评价记录 | 维护跟单员历史服务评价记录 |
| | 考核结果表 | 生成跟单员考核结果汇总表 |

## 五、数据统计模块

### 5.1 业务数据统计

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **投保统计** | 投保数据汇总 | 从系统业务数据中提取并汇总投保相关数据，包括投保数量、投保金额、投保率等 |
| | 统计口径管理 | 按照统一的统计口径和周期规则进行数据统计，确保数据一致性 |
| | 统计报表生成 | 按照统计报表模板生成投保统计报表 |
| **限额统计** | 限额数据汇总 | 汇总各买方的信用限额申请数据，包括申请数量、审批通过率、额度使用情况等 |
| | 统计报表生成 | 生成限额统计报表 |
| **出运统计** | 出运数据汇总 | 汇总出运申报数据，包括出运数量、出运金额、申报及时率等 |
| | 统计报表生成 | 生成出运统计报表 |

### 5.2 风险数据分析

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **赔付率分析** | 赔付数据统计 | 从理赔数据中提取赔付相关信息，计算赔付率等指标 |
| | 分析维度 | 按照分析维度和计算逻辑进行多维度赔付率分析（按地区、按行业、按买方等） |
| | 分析报告生成 | 生成赔付率分析报告 |
| **逾期率分析** | 逾期数据统计 | 统计应收账款逾期情况，计算逾期率等指标 |
| | 分析维度 | 按照逾期分析维度进行多角度分析 |
| | 分析报告生成 | 生成逾期率分析报告 |
| **买方风险分析** | 买方风险评估 | 基于理赔和账款数据，对买方进行风险评估和信用评级 |
| | 风险预警 | 设置风险预警规则，对高风险买方进行自动预警 |
| | 风险分析报告 | 按照风险分析报告模板生成买方风险分析报告 |

## 名词解释

| 名词 | 说明 |
|------|------|
| 应用文件（外部） | 服务商标准的文件资料或合同模版、合同条款、保单条款等 |
| 内置规则 | 常量管理规则-服务商的流程和期限要求等 |
| 平台规则 | 平台系统内部的匹配规则、流程管理规则、支付规则等 |
| 资料清单 | 支撑各功能模块、功能、事项的字段清单、流程规则梳理等 |
