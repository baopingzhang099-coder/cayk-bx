## 一、保险购买模块

（沿用 V1 结构，字段详单以投保页面表单为准；本次补充重点在“保单管理/出运/理赔”模块的字段与规则。）

### 1.1 投保信息管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **投保信息录入** | 客户基本信息 | 支持企业用户填报、系统导入客户基本信息，包含企业名称、联系人、联系方式、企业资质等字段 |
| | 买方信息 | 支持客户填报/贸易资料解析采集买方信息，包括买方名称、信用评级、历史交易记录等 |
| | 贸易信息 | 通过贸易资料解析获取贸易相关信息，包括商品信息、交易金额、付款方式等 |
| | 购买需求 | 支持客户填报/录入保险购买需求，包括投保金额、保障范围、预期保险公司偏好等 |
| **投保信息数字化** | 投保资料整理 | 对客户提交资料和贸易资料进行系统化整理，形成完整的投保档案 |
| | 保险购买需求整理 | 根据客户需求和贸易信息，整理形成标准化的保险购买需求文档 |
| | 投保申请资料整理 | 整理生成投保申请书、买方信息采集表等正式投保申请材料 |

### 1.2 投保流程管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **投保方案确认** | 投保方案推介 | 根据客户投保需求、贸易信息、国别行业风险等条件，系统自动匹配并推荐保险方案 |
| **申请投保** | 申请投保 | 平台自动提取投保申请书、买方信息采集表等资料，生成投保申请单 |
| **提交投保申请** | 提交投保申请 | 完成流程校验和任务管理，支持线上提交投保申请至保险公司 |
| **审核流转** | 审核流转 | 管理投保申请的审核流程，跟踪各审核节点状态，处理审核意见反馈 |
| **核保** | 核保 | 配合保险公司进行核保流程管理，接收核保结果并反馈客户 |
| **保单签发** | 保单获取 | 获取保险公司签发的正式保单，支持电子保单接收和解析 |
| **支付管理** | 支付管理 | 提取保单明细表、费率表信息，管理保费支付流程，跟踪支付状态 |

### 1.3 数据报表管理

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **保单数字化** | 信息字段整理 | 从流程中提取关键字段，整理保单编号、被保险人、保险公司、保险期限等核心信息 |
| | 流程整理 | 梳理投保全流程节点和时间线，形成标准化流程记录 |

### 2.3 信用限额管理（新增规则与字段补充）

### 2.5 流程管理（续保/退保/到期/中止）

| 一级功能 | 二级功能 | 三级功能页面 | 功能描述 |
|---------|---------|-------------|---------|
| **生效通知** | 生效通知 | 保单详情 | 当保单生效时自动更新状态并发送通知 |
| **中止通知** | 中止通知 | 保单详情 | 当保单因故中止时更新状态并发送通知（需审核申请文件） |
| **到期提醒** | 到期提醒 | 提醒中心 | 到期前30天自动提醒续保与限额到期 |
| **续保申请** | 续保申请启动 | 续保表单 | 建议到期前30天启动；续保会评估赔付率/限额利用率并生成新保单与新限额批复 |
| **续保空窗期** | 空窗期处理 | 提示与冻结 | 空窗期内原则上无保障覆盖；暂停出运申报 |
| **退保管理** | 退保处理 | 退保表单 | 按短期费率计算退费；需提交退保申请书/保单正本/原因说明等 |
