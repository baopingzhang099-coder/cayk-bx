## 三、业务流程图

> 以下三个泳道图分别对应保险投保、保单管理、保险理赔三大核心业务流程。角色泳道包括：客户、长安银科平台、跟单员、保险公司。流程图涵盖各角色间的协作关系与关键流转节点。

### 3.1 保险投保流程

```mermaid
flowchart LR
  subgraph 客户
    direction TB
    C1[填写投保需求] --> C2[提交企业资料\n与买方信息] --> C3[补充资料] --> C4[缴费确认\n保单生效]
  end

  subgraph 长安银科平台
    direction TB
    P1[需求采集与校验\nAI解析资料] --> P2[数据整理与分析\n生成数字化推荐方案] --> P3[派单分配\n指派跟单员]
  end

  subgraph 跟单员
    direction TB
    K1[确认投保信息\n与客户沟通] --> K2[收集补充资料] --> K3[递交资料\n至保险公司]
  end

  subgraph 保险公司
    direction TB
    I1[买方资信调查\n≤1个月] --> I2[信用限额审批\n≤2周] --> I3[信保核保] --> I4[出具保单\n保单数字化]
  end

  C2 -->|提交| P1
  P2 -->|推荐方案| C1
  P3 -->|分配| K1
  C3 -->|补充| K2
  K3 -->|递交| I1
  I4 -->|出单| C4
  I3 -.->|退回补充资料| K2
  K2 -.->|退回| C2
```

**流程说明：**
1. 客户在平台填写投保需求并提交企业基本资料与买方信息
2. 长安银科平台AI解析资料，自动填充客户基本信息，生成数字化推荐投保方案
3. 平台派单给跟单员，跟单员与客户沟通确认投保信息
4. 如需补充资料则退回给客户补充，补充完成后跟单员递交资料至保险公司
5. 保险公司进行买方资信调查（1个月内）、信用限额审批（2周内）、核保
6. 核保通过后出具保单，客户缴费确认，保单生效
7. 如核保退回，补充资料后重新递交

### 3.2 保单管理流程

```mermaid
flowchart LR
  subgraph 客户
    direction TB
    C1[签署委托合同] --> C2[保费支付\n上传缴费凭证] --> C3[信用限额申请] --> C4[出运申报\n提交出运信息] --> C5[保单维护\n续保/变更/退保]
  end

  subgraph 长安银科平台
    direction TB
    P1[合同确认\nOCR识别缴费凭证] --> P2[保费到账确认] --> P3[限额审核\n闲置预警60/90天] --> P4[出运校验\n超限拦截/期限校验] --> P5[维护审批\n结果同步]
  end

  subgraph 跟单员
    direction TB
    K1[核保材料提交\n补充资料收集] --> K2[资料移交\n递交至保险公司] --> K3[限额跟踪\n使用率监控] --> K4[申报资料下载\n线下提交至保险方]
  end

  subgraph 保险公司
    direction TB
    I1[核保审核\n通过/拒绝] --> I2[出具正式保单] --> I3[限额审批] --> I4[承保确认]
  end

  C1 -->|签署| P1
  P1 -->|确认| C2
  C2 -->|凭证| P2
  P2 --> K1
  K1 --> I1
  I1 -->|通过| K2
  K2 --> I2
  I2 --> C3
  C3 --> P3
  P3 --> I3
  I3 --> C4
  C4 --> P4
  P4 --> K3
  K3 --> K4
  K4 --> I4
  C5 --> P5
  I1 -.->|拒绝/退回| K1
  K1 -.->|退回补充| C1
```

**流程说明：**
1. 客户与长安银科签署委托合同，长安银科确认后进入保费支付环节
2. 客户上传缴费凭证，长安银科进行OCR识别确认缴费到账
3. 跟单员收集核保材料，提交至保险公司核保
4. 保险公司核保通过后出具正式保单，未通过则退回补充资料
5. 客户申请信用限额，平台审核后提交保险公司审批
6. 客户进行出运申报，平台校验超限/期限/保费冻结规则
7. 跟单员下载申报资料，线下提交至保险公司进行承保确认
8. 保单维护阶段支持续保、变更、退保操作，长安银科审批后结果同步

### 3.3 保险理赔流程

```mermaid
flowchart LR
  subgraph 客户
    direction TB
    C1[报案\n可损申报告知] --> C2[上传理赔资料\n索赔材料提交] --> C3[资料补充\n按要求补充] --> C4[收款确认\n赔款到账]
  end

  subgraph 长安银科平台
    direction TB
    P1[接收案件通知\n校验资料完整性] --> P2[指派跟单员] --> P3[权益转让\n融资办理]
  end

  subgraph 跟单员
    direction TB
    K1[接单\n接手理赔案件] --> K2[资料审核\n完整性校验] --> K3[线下递交\n至保险公司]
  end

  subgraph 保险公司
    direction TB
    I1[接收案件\n定损核赔] --> I2[赔付审核\n记录审核] --> I3[赔款支付\n到账确认]
  end

  C1 -->|报案| P1
  P1 -->|完整| P2
  P2 -->|指派| K1
  K1 -->|通知| C2
  C2 -->|提交| K2
  K2 -->|不完整| C3
  C3 -->|补充完成| K2
  K2 -->|完整| K3
  K3 -->|递交| I1
  I1 --> I2
  I2 --> I3
  I3 -->|赔付| C4
  C4 -->|权益转让| P3
```

**流程说明：**
1. 客户发起报案（可损申报告知），长安银科平台接收案件通知并校验资料完整性
2. 资料完整则指派跟单员，跟单员接单后通知客户上传理赔资料
3. 客户提交索赔材料，跟单员审核资料完整性
4. 如资料不完整退回客户补充，补充完成重新提交
5. 资料完整后跟单员线下递交至保险公司
6. 保险公司进行定损核赔、赔付审核，最终支付赔款
7. 客户确认赔款到账，办理权益转让与融资手续

| 高赔付率费率上浮 | 续保时上年赔付率>60% | 续保费率上浮 | |
| 限额利用率低费率优化 | 续保时限额利用率<50% | 缩减买方清单→保费下调 | |

### 9.4 理赔新建合规校验

| 校验点 | 规则 | 触发时机 | 提示方式 | 备注 |
| --- | --- | --- | --- | --- |

| 报案时限 | 超过报案时限需特殊说明 | 提交理赔时 | 阻断提交+错误提示 | |
